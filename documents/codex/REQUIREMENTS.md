# 要件定義

## 目的

Tableau Desktop / Prep ファイルを変更せずに読み取り、内部構造、接続関係、処理内容をブラウザで確認できるようにする。

## 機能要件

- `.twb`, `.twbx`, `.tds`, `.tdsx`, `.tfl`, `.tflx` を受け付ける。
- 複数ファイルを独立して処理し、個別にエラーを表示する。
- Desktop は構造、datasource relationship / join、dashboard action、zone / layout、詳細表を表示する。
- Prep はノード、接続、アクション、フィールド変化を表示する。
- Desktop は単一 HTML、Prep は HTML とフロー構造 JSON を出力する。
- 通常ログと Debug mode の詳細ログを生成し、画面からダウンロード可能にする。
- Streamlit の再実行では同じファイルの高コスト処理をキャッシュする。

## セキュリティ要件

- XML の外部エンティティ解決とネットワークアクセスを無効にする。
- HTML に埋め込む値は JSON 直列化し、script 終端文字列を無害化する。
- 一時ファイルは処理スコープ終了時に削除する。
- ローカルの Tableau ファイル、生成物、ログ、秘密設定を Git 管理しない。

## 非機能要件

- 未対応要素があっても、可能な範囲の結果を表示する。
- エラーには対象ファイル名を含め、詳細はログへ記録する。
- 公開文書と内部資料を分離する。
- Windows 埋め込み Python と一般の Python 仮想環境の両方で実行可能にする。

## 現在の未達要件

- ZIP の展開量、圧縮率、メンバー数にアプリ独自の上限がない。
- 依存関係のバージョンが固定されておらず、再現可能な配布ビルドが定義されていない。
- CI と静的解析の設定がない。
- 公開ライセンスと脆弱性報告先が未確定。
