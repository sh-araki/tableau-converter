# Contributing

Issue と Pull Request を歓迎します。

## 開発手順

1. Python 3.10 以上の仮想環境を作成します。
2. `python -m pip install -r requirements.txt` を実行します。
3. 変更前後にプロジェクト内部で定めたテストを実行します。
4. 新しい Tableau 構造へ対応する場合は、匿名化した最小の単体テストを追加します。
5. 利用者に見える変更は `documents/public/README.md` と `documents/public/CHANGELOG.md` を更新します。

## コーディング方針

- 読み込み、抽出、変換、画面表示の責務を分けます。
- 未対応の構造では、可能な範囲の結果を残し、対象が分かるエラーまたはログを出します。
- DataFrame の列を参照する前に、空データやバージョン差を考慮します。
- 元ファイル由来の文字列を HTML へ埋め込む場合は、安全な JSON 直列化と HTML エスケープを行います。
- `python -B` または同梱スクリプトを使い、不要な bytecode を作らないようにします。

## テストデータ

テスト一式は内部開発用です。実ファイルには機密情報が含まれる可能性があるため、接続情報、個人名、絶対パス、抽出データを公開しないでください。

## Pull Request

- 変更目的と対応形式を記載してください。
- 実行したテストと結果を記載してください。
- 接続情報、認証情報、個人名、ローカルパス、生成レポートを含めないでください。
