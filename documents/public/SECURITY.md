# Security Policy

## 対象

最新版のコードをセキュリティ修正の対象とします。

## 脆弱性の報告

認証情報の露出、XML / ZIP 処理、生成 HTML のスクリプト実行などに関する問題は、公開 Issue に機密情報を書かず、リポジトリ管理者が指定する非公開連絡先または GitHub Private Vulnerability Reporting で報告してください。公開前に、実際の連絡先をこの文書へ追記してください。

## ファイル取り扱い上の注意

- Tableau ファイルには接続先、ユーザー名、ローカルパス、抽出データが含まれる場合があります。
- 信頼できないファイルは隔離されたローカル環境で処理してください。
- 生成 HTML、フロー JSON、ログにも元ファイル由来の情報が含まれます。共有前に内容を確認してください。
- Debug mode のログは通常時より多くの解析情報を含みます。

## 実装上の対策

- XML 解析では外部エンティティ解決とネットワークアクセスを無効にしています。
- 埋め込み JSON 内の `</script>` を無害化してから HTML に挿入します。
- アップロードは一時ディレクトリで処理し、処理終了後に削除します。

ZIP 展開量、圧縮率、メンバー数、アップロードサイズについて、アプリ独自の上限はまだ設けていません。信頼できない大容量ファイルを扱う環境では、Streamlit または実行基盤側でも上限を設定してください。
